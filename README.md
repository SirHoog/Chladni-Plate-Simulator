# Chladni Plate Simulator
A digital simulation of the Chladni Plate Experiment (a real life physical phenomenon where sound waves vibrate particles on a metal plate to produce intricate visual patterns)

A project/submission for [HackClub Crescent](https://crescent.hackclub.com) - [Week 4 - The Visualizer card](https://crescent.hackclub.com/guides/visualizer)

## Installation
1. Clone repository: `git clone https://github.com/SirHoog/Chladni-Plate-Simulator.git`
2. Create a virtual environment:
    - In terminal: `python -m venv .venv`
    - In VS Code Command Palette: Click ***"Python: Create Environment..."***
3. Activate the virtual environment in the terminal:
   - Linux/macOS: `source .venv/bin/activate`
   - Windows: `.venv\Scripts\activate`
4. Install required dependencies: `pip install -r requirements.txt`
5. Have fun! :D
